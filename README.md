🎮 **[¡Jugar la versión web directamente en itch.io!](https://ortizdariojosue-design.itch.io/you-never-should-have-entered)**

## 📌 Sobre el Proyecto

**You Never Should Have Entered** es una experiencia de horror de supervivencia en 2D inspirada en el lore de las *Liminal Spaces* y *The Backrooms*. El jugador asume el rol de un investigador de la corporación **NEXUS Dynamics** que sufre un accidente en el campo y termina atrapado en el Nivel 0.

El objetivo principal es explorar 5 niveles distópicos, gestionar recursos críticos y encontrar una salida de regreso a la realidad.

---

## ⚡ Mecánicas Principales & Sistemas Integrados

* **Gestión de Estamina:** El movimiento avanzado (correr, dashear y realizar doble salto) consume estamina. Requiere un uso estratégico durante las persecuciones.
* **Mecánica de Linterna UV:** Permite iluminar escenarios oscuros y repeler entidades hostiles mediante el modo de luz UV (tecla Espacio). El uso continuo agota la batería, obligando al jugador a buscar repuestos por el mapa.
* **Sistema de Cordura y Salud:** Administración de recursos para evitar perder el control del personaje y recolección de *Almond Water* para restaurar la salud.
* **Diseño de Niveles:** 5 entornos temáticos con progresión de dificultad (Yellow Rooms, Funrooms, Poolrooms, Abandoned Station, Redrooms).

## 🕹️ Controles

| Acción | Tecla | Notas |
| :--- | :--- | :--- |
| **Moverse** | `Flechas Izq / Der` | Desplazamiento lateral |
| **Trepar / Interactuar** | `Flechas Arriba / Abajo` | Escaleras y objetos |
| **Doble Salto** | `Arriba` + `Arriba` | Requiere al menos 50% de estamina |
| **Correr** | `Shift` | Consume estamina |
| **Dash / Embestida** | `A` | Consume estamina |
| **Combo Aéreo** | `Salto` + `A` | Salto + Dash en el aire para mayor alcance |
| **Modo Linterna / UV** | `Espacio` | Alterna modo de luz / consume batería / repela enemigos |
